# Contributing to NyaySetu

Thank you for your interest in contributing to **NyaySetu**! We welcome contributions that help improve accessibility to legal services in Hindi.

## 📌 How to Contribute

### 1. Fork the Repository

Click on the **Fork** button and clone your fork:

```bash
git clone https://github.com/your-username/nyaysetu.git
cd nyaysetu
```

### 2. Create a Branch

Create a new branch for your feature or bug fix:

```bash
git checkout -b feature/your-feature-name
```

### 3. Make Changes

* Write clean, readable, and well-structured code
* Follow consistent naming conventions
* Add comments where necessary

### 4. Commit Changes

```bash
git commit -m "Add: short description of your changes"
```

### 5. Push to GitHub

```bash
git push origin feature/your-feature-name
```

### 6. Create a Pull Request

* Go to your forked repo
* Click **New Pull Request**
* Clearly describe your changes

---

## 🛠 Contribution Guidelines

* Ensure your code works properly before submitting
* Avoid breaking existing functionality
* Keep pull requests small and focused
* Follow project structure and coding style

---

## 🐞 Reporting Issues

If you find a bug or want to request a feature:

* Go to the **Issues** tab
* Describe the problem clearly
* Include screenshots if needed
